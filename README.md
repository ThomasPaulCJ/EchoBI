# ECHO-BI: Smart Data Interpreter 📊

[![Python Version](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Made with Streamlit](https://img.shields.io/badge/Made%20with-Streamlit-red.svg)](https://streamlit.io)

A modern, AI-powered business intelligence dashboard that simplifies data analysis. ECHO-BI allows users to upload datasets, receive intelligent chart recommendations, generate automated insights, and ask questions about their data in natural language—all powered by local AI models for complete privacy and offline capability.



## ✨ Core Features (Phase 1)

* **Automated Data Ingestion & Cleaning** for CSV/Excel files.
* **AI-Powered Chart Recommendation** using a custom-trained XGBoost model.
* **Automated Data Summaries & Insights** generated by a local LLM.
* **Natural Language Q&A** for conversational data exploration.
* **Dynamic & Automated Chart Plotting** of the recommended visualizations.
* **Interactive Outlier Detection** with an adjustable Z-score threshold.
* **Text-to-Speech Synthesis** for accessible audio playback of AI insights.
* **Custom-Built, Professional Dark UI** for a focused user experience.

## 🛠️ Tech Stack

* **Application Framework:** Streamlit
* **Data Manipulation:** Pandas, NumPy

## 🚀 Getting Started

Follow these instructions to set up and run the project on your local machine.

### Prerequisites

1.  **Python 3.9+** installed on your system.
2.  **LM Studio:** Download and install from [lmstudio.ai](https://lmstudio.ai/).
    * Download a GGUF model within LM Studio (e.g., Llama 3 8B Instruct).
    * Ensure the local server is running.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/ECHO-BI.git](https://github.com/your-username/ECHO-BI.git)
    cd ECHO-BI
    ```

2.  **Create and activate a virtual environment:**
    * On macOS/Linux:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```
    * On Windows:
        ```bash
        python -m venv venv
        .\venv\Scripts\activate
        ```

3.  **Install the required libraries:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Train the ML Model:** The chart recommender is a custom-trained model. Run the training script to generate the `chart_recommender.pkl` file.
    ```bash
    python training.py
    ```

### Running the Application

1.  **Start the AI Server:**
    * Open LM Studio.
    * Load your desired model.
    * Navigate to the "Local Server" tab (icon: `</>`) and click **"Start Server"**.

2.  **Run the Streamlit App:**
    * Open a new terminal, navigate to the project folder, and activate your virtual environment.
    * Run the following command:
        ```bash
        streamlit run app.py
        ```
    * Your web browser should automatically open with the ECHO-BI dashboard.

## 🏛️ Project Architecture Plan

This project is being developed in two phases for our Final Year Project submission.

* **Phase 1 (Complete):** A fully functional, standalone AI dashboard built with Streamlit. This provides a robust and rapidly-developed proof-of-concept with a polished user experience.
* **Phase 2 (Planned):** Evolution into a full-stack web application. The backend logic will be migrated to a **FastAPI** application, exposing REST endpoints. The frontend will be rebuilt from scratch using **React** to create a scalable, production-grade software product.
