## 🚀 Quick Start Guide

### Backend Setup
```bash
cd backend
source echovenv/bin/activate  # Activate virtual environment
uvicorn main:app --reload --port 8000
```

### Frontend Setup
```bash
cd frontend/echo-bi
npm install
npm run dev  # Starts on http://localhost:5173
```

### Access Application
- **Frontend:** http://localhost:5173
- **Backend API:** http://localhost:8000/docs (Swagger UI)
